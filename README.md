# 网页桌面 · Web Desktop

把现有网页区域变成手机桌面式网格：拖动交换、拉角缩放、自动补位、撤销和恢复。浏览器扩展原型，基于 [GridStack 14.0.0](https://github.com/gridstack/gridstack.js) 的布局引擎。

## 能做什么

- 选择原网页中的一个区域，把其直接子元素变成网格组件。
- 拖到另一个组件上交换位置；大小不同时，为目标位置腾出空间。
- 拉右下角按格子放大/缩小；缩小或移动后自动补位。
- 撤销/重做、恢复网站原布局并删除本页保存记录。
- 保存到本机；授权指定网站后，刷新或重启浏览器自动恢复。
- 保留原 DOM 节点及其父节点，不复制 HTML、不代理网站接口。
- 检测区域成员被网站新增、删除、替换时停止布局并恢复样式。

## 本地运行

需要 Node.js 20+。依赖只有 GridStack，扩展运行时不请求 CDN 或后端。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4178 ，点击“编辑这个工作台”。拖蓝框交换，拉右下角调整大小，点“完成编辑”后测试搜索、计数、标签和输入框。

## 安装扩展（Chrome / Edge）

1. 构建后，在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式。
2. 选择“加载已解压的扩展”，指定项目的 `dist` 文件夹。
3. 在普通网页点击扩展图标 → “打开布局编辑器”。
4. 点击“选择一个网页区域”，在两个模块之间的空白处选择它们共同的容器。蓝框确认选中了正确区域后再单击。
5. 拖动调整后点击“完成编辑”。
6. 若需下次自动恢复，在扩展弹窗点击“允许此网站自动恢复布局”，接受浏览器针对该网站的权限请求。

编辑面板也支持选中组件后点击放大/缩小；聚焦蓝框时方向键移动，Shift + 方向键调整尺寸，Esc 取消选择或拖动。

## 已验证与限制

本地在 Windows + Edge 无头浏览器验证了实际鼠标拖动、缩放、撤销重做、事件监听、事件委托、表单提交、输入保留、刷新及浏览器重启恢复、恢复原布局、动态新增节点后的安全回退。

扩展测试使用独立浏览器配置和仅预授权本地回环地址的测试副本。生产扩展仍使用可选网站权限；原生权限确认弹窗未自动化测试。尚未在用户登录的第三方业务网站上做兼容性验证。

当前版本的边界：

- 每个页面支持一个区域，2–100 个可见直接子元素；不支持把不同父节点中的元素合并到一个区域。
- 页面标识为 origin + pathname。相同路径的查询参数、hash 视为同一页面；不适合依赖 query/hash 区分完全不同布局的网站。
- 同一容器内视觉位置可变，但 DOM 顺序/键盘 Tab 顺序保持原样。
- 调整的是组件占用空间，内容不做字体缩放；过小内容可滚动。
- iframe、Shadow DOM 内部、Canvas、表格行、浏览器内部页面不支持。
- 网站改变区域成员时恢复原样，需要重新选择；不会强行覆盖框架渲染。
- 没有跨设备同步、App 内部界面修改、主题市场或任意网站兼容保证。
- 当前无图标素材、无遥测、无账号系统。扩展本地记录选择器、标签类型/标识及格子位置，不存 HTML、表单值、Cookie 或请求内容。

## 测试

```sh
npm test
# 保持 npm start 运行，另开终端：
npm run test:browser
npm run test:extension
```

浏览器测试复用本机 Playwright（优先项目依赖；开发环境也探测已有 Codex runtime），可自行安装 `playwright` 开发依赖。默认使用 Windows 已安装的 Edge；通过 `node tests/browser.cjs /path/to/browser` 指定其他 Chromium 浏览器。扩展测试的管理页探测目前针对 Edge。

更多设计依据见 [选型与验收](docs/DECISIONS.md)。
